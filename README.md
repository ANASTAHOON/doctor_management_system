# 🩺 Doctors' Salary Statistics – Dart Console App

This is a simple Dart console application that collects doctors' names and their monthly salaries, then calculates and displays useful statistics such as:

- Total number of doctors
- Total salary amount
- Average salary
- Highest salary
- Lowest salary

## 🚀 Features

- Interactive input for doctor names and salaries
- Validates salary inputs using `double.tryParse`
- Calculates:
  - Total number of doctors
  - Sum of all salaries
  - Average salary
  - Highest and lowest salary
- Clean and user-friendly terminal output

## 🛠️ Technologies Used

- Dart programming language
- `dart:io` for user input
- `List`, `double`, `int` for data storage and calculations
